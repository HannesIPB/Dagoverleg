☁️ Cloud synchronisatie instellen

Vul uw Firebase Database URL in. Alle data wordt automatisch gesynchroniseerd tussen alle PC's.

Te vinden in Firebase Console → Realtime Database → de URL bovenaan
Stap voor stap (5 minuten):
1. Ga naar console.firebase.google.com
2. Klik Add project → naam: dagoverleg → Google Analytics: uit → Create
3. Klik links op Build → Realtime Database
4. Klik Create Database → kies Europe (belgium) → klik Next
5. Kies Start in test mode → klik Enable
6. Kopieer de Database URL bovenaan (eindigt op .firebasedatabase.app)
7. Plak die URL hierboven en klik Opslaan
Test mode = iedereen met de URL kan lezen en schrijven (ideaal voor intern gebruik). Na 30 dagen moet u de regels verlengen in Firebase Console.
P1 — Geplande uren per lijn (max 168u)
P4 — Geplande uren per lijn (max 120u)
IDE RT — Geplande uren (max 161u · 500 kg/u)
